隐私说明
Privacy notice

更新日期 / Updated: 2026-10-21

适用于由单一拥有者自行管理的 V5 Auto Deploy。真实授权与发布目前尚未启用；下述操作仅在拥有者明确同意并完成配置后开展。

This notice covers V5 Auto Deploy, managed by and for one owner. Live authorization and releases are not yet enabled. The operations described below require the owner's explicit approval and completed configuration.

1. 数据与用途 / Data and purpose

拟处理的数据包括：Apps Script项目源代码、清单、版本与部署元数据、变更计划和操作回执，以及完成授权所需的OAuth客户端信息、访问令牌和刷新令牌。用途限于拥有者要求的目标核验、代码备份、发布与恢复。源代码可能包含拥有者写入的配置或信息，应在启用前检查，避免内嵌秘密。

Intended data includes Apps Script source code, manifests, version and deployment metadata, change plans and receipts, plus OAuth client information, access tokens and refresh tokens needed for authorization. Use is limited to owner-requested target checks, backups, releases and recovery. Source code may contain owner-supplied configuration or information and should be checked for embedded secrets before activation.

仅请求 script.projects 与 script.deployments 两项Google权限。OAuth权限本身不只限于单个脚本；应用会额外核验固定目标。不出售这些数据，不将其用于广告、用户画像或其他无关用途。

Only the Google scopes script.projects and script.deployments are requested. The OAuth grant is not inherently limited to one script; the application adds target checks. This data is not sold or used for advertising, profiling or unrelated purposes.

2. 服务提供方 / Service providers

Google通过OAuth、Apps Script API及一次性Cloud Shell配置环境处理相应数据。经拥有者同意，GitHub接收加密的授权材料和私有加密备份，并在获准的Actions工作流中使用凭据处理脚本数据。GitHub可解密其Secrets以供工作流使用；能修改获准运行的工作流者也可能获得运行时凭据。加密不等于对所有服务提供方不可见。

Google processes relevant data through OAuth, the Apps Script API and the one-time Cloud Shell setup environment. With the owner's consent, GitHub receives encrypted authorization material and private encrypted backups, and uses credentials in approved Actions workflows to process script data. GitHub can decrypt its Secrets for workflow use; someone able to change an executing workflow may also obtain runtime credentials. Encryption does not make data invisible to every service provider.

本工具不会自动把Google API数据发送到广告服务或通用AI服务。若拥有者另行要求其他人员或服务处理具体数据，应先说明接收方、目的与范围并取得相应授权。

The tool does not automatically send Google API data to advertising or general-purpose AI services. Any separately requested processing by other people or services requires disclosure of the recipient, purpose and scope, with the applicable authorization.

3. 凭据与保留期限 / Credentials and retention

首次配置助手在进程内处理GitHub临时令牌、Google客户端JSON与OAuth响应，不主动将这些明文写入本地文件。客户端秘密及刷新令牌先加密，再存入拥有者私有仓库的GitHub Actions Secrets。它们没有本工具设定的自动删除期限，可能保留到拥有者移除；Google授权也可能到期或被撤销。浏览器下载的客户端文件由拥有者管理。

The setup helper processes the temporary GitHub token, Google client JSON and OAuth responses in memory and does not intentionally write them as plaintext local files. The client secret and refresh token are encrypted before storage in the owner's private GitHub Actions Secrets. The tool sets no automatic deletion deadline for these secrets; they may remain until removed by the owner. Google authorization may expire or be revoked. Downloaded client files remain under the owner's control.

代码备份与操作回执在上传前加密，工作流申请90天保留并核对到期信息。提前删除artifact、运行记录或仓库可能缩短保留时间。恢复还需要原备份密钥；不要在不再需要相关备份之前丢弃密钥。云平台日志、内存处理和基础设施副本受相应提供方政策约束，不承诺物理即时清除。

Code backups and receipts are encrypted before upload. The workflow requests 90-day retention and checks expiry information. Deleting an artifact, workflow run or repository may shorten that period. Recovery also requires the original backup key; retain it while those backups are needed. Platform logs, memory handling and infrastructure copies are subject to provider policies; immediate physical erasure is not promised.

4. 撤销与删除 / Revocation and deletion

拥有者可在Google账号的第三方应用访问设置中撤销Google授权，并在GitHub设置中删除相应Actions Secrets、撤销临时个人访问令牌，按需删除备份artifact或运行记录。撤销授权不会自动删除已保存的备份；删除GitHub Secret也不会自动撤销Google授权。本工具尚未提供一键清除全部数据的功能。

The owner can revoke Google access in Google Account third-party access settings, remove the corresponding GitHub Actions Secrets, revoke the temporary personal access token, and delete backup artifacts or workflow runs as needed. Revocation does not automatically delete existing backups; deleting a GitHub Secret does not automatically revoke Google authorization. The tool does not currently provide a one-click delete-all function.

V5 Auto Deploy's use and transfer of Google API data must comply with the Google API Services User Data Policy, including Limited Use requirements. Access and transfers are limited to disclosed, owner-authorized features. New uses require updated disclosures and applicable consent before they begin. This does not imply Google verification or endorsement.

本工具仅供拥有者自用，不接受其他用户注册或数据提交。拥有者通过自己的Google与GitHub账号执行上述访问和删除控制；本页更新日期用于识别说明版本。

This is an owner-only tool, with no registration or data submission for other users. The owner uses their own Google and GitHub accounts to exercise the access and deletion controls above. The date on this page identifies the notice version.
