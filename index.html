V5 Auto Deploy

配置准备中 · Setup in progress

为单一拥有者准备的 Google Apps Script 代码备份与发布工具，旨在减少反复手工复制代码，并在变更前核对目标、保留可恢复的备份。

A personal Google Apps Script backup and release tool for a single owner. It is designed to reduce repeated manual code copying, check the intended target, and preserve recoverable backups before changes.

当前状态 / Current status

实现已进行离线测试，但真实账号授权和正式发布尚未启用。本说明介绍拟启用的处理方式，不表示线上发布已经可用。

The implementation has been tested offline. Live account authorization and production releases are not yet enabled. These pages describe the intended operation, not an already operational release service.

先核对，再变更
Check before changing

启用后，工具将核对指定项目及现有部署，备份代码与部署元数据，并仅按拥有者确认的方案更新。发布操作与首次授权分开批准。

Once enabled, the tool will verify the selected project and existing deployment, back up code and deployment metadata, and apply only an owner-approved plan. Release approval is separate from initial authorization.

明确的恢复窗口
A defined recovery window

拟使用私有 GitHub 仓库保存加密备份和回执，申请保留90天。恢复需要原备份密钥及仓库访问权限；这不是永久备份承诺。

Encrypted backups and receipts are intended for a private GitHub repository with a requested retention period of 90 days. Recovery requires the original backup key and repository access; this is not permanent archival storage.

授权范围 / Permissions

工具只请求 https://www.googleapis.com/auth/script.projects 和 https://www.googleapis.com/auth/script.deployments 两项 Google OAuth 权限，用于读取与更新 Apps Script 项目和部署。Google授予的权限可覆盖该账号有权访问的项目；工具自身再限制到核对过的目标。

The tool requests only the two Google OAuth scopes shown above, for Apps Script projects and deployments. The Google grant can cover projects accessible to the account; the tool further restricts operations to its verified target.

Google处理授权和脚本API请求；GitHub处理经同意保存的凭据、私有加密备份及后续工作流运行。本工具不是Google或GitHub的官方产品，也不面向公众开放注册。

Google processes authorization and script API requests. GitHub processes consented credential storage, private encrypted backups and later workflow execution. This is not an official Google or GitHub product and does not offer public registration.
